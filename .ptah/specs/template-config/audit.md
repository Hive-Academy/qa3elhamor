# template-config: audit of owner- and brand-specific values

Every value that made the site "the owner's" rather than "a template", where it lived before this
item, and where it resolves from now. "Content" = `content/*.json` (CMS-editable), "config" =
`apps/web/src/site.config.ts`, "env" = build-time environment (`.env.example`), "asset config" =
the asset manifest in `libs/world/domain` (models and their credits).

## Words that name the owner

| Value | Lived in (before) | Resolves from (now) |
| --- | --- | --- |
| Name, headline, bio, location, skills, links | `content/site.json` | content (unchanged); a fork starts from `content.example/` via `npm run template:reset` |
| "Send privately to Abdallah" / "Only he reads it…" | `apps/web/src/app/wall/wall-copy.ts` (UI table, en + ar) | content: `copy.complaintPrivateLabel`, `copy.complaintPrivateHint` |
| "It reaches Abdallah's desk…", "…reach him", public-filed line | `apps/web/src/app/bureau/bureau-copy.ts` (`FILED_LINES`) | content: `copy.complaintFiledLine`, `complaintFiledUnsentLine`, `complaintFiledPublicLine` (`filedLines(copy)`) |
| Owner name in narration, credits, complaint intro | `content/narration.json`, `credits.json`, `site.json` | content (unchanged; replaced by the sample on reset) |
| Contact email sender "Qaa El-Hamour Complaints Bureau" | `contact-submitters.ts` (hard-coded `from_name`) | config: `SITE.brand.contactFromName` (injected through `createContactSubmitter`) |

## Page metadata

| Value | Lived in | Resolves from |
| --- | --- | --- |
| `<title>Qaa El-Hamour \| قاع الهامور</title>` | `apps/web/index.html` | content `copy.siteTitle` (default language) at build; the visitor's language at run time (`app.tsx`) |
| `<meta name="description">` | `index.html` | content `copy.siteDescription` |
| `theme-color` `#0a1e3f` | `index.html`, `moderation.html` | config `SITE.theme.sea` |
| Open Graph / Twitter card | absent | generated: content title/description, `SITE.meta.siteName`, `SITE.meta.ogImage`, env `SITE_URL` (absolute URLs only when set) |
| Favicon `%BASE_URL%favicon.ico` (moderation: `/favicon.ico`, not base-aware) | both HTML entries | config `SITE.meta.favicon`, base-aware in both |
| "Moderation \| Qaa El-Hamour" | `moderation.html` | `Moderation \| ${SITE.meta.siteName}` |
| `<html lang="en">` | `index.html` | `SITE.locales[0]` (+ `dir`) |

All generated by `apps/web/src/site-build.ts` (`siteTemplate()` in `vite.config.mts`) at the
`<!-- site:head -->` marker; the CSP plugin still runs after it and anchors after `<meta charset>`.

| Page night/foam/sand, nav bar `rgba(10,30,63,.94)` | `page-view.css` | `--theme-sea` / `--theme-foam` / `--theme-paper`, `color-mix(… 94%, transparent)` |

| `--font-ui`, `--font-paper` | `styles.css` `:root` | `SITE.theme.fontUi`, `fontPaper` |

All 15 theme values are written as `:root` custom properties by the `virtual:site-theme.css`
module (bundled into the stylesheet, CSP-safe), imported by both entries.

Left in component CSS (secondary art, not brand): stamp inks, cork/stone of the notice board,
speech-bubble colours, beacon label, rods. A fork that needs them changes component CSS.

| Value | Lived in | Resolves from |
| --- | --- | --- |
| Landmark placements | `dive.config.ts` (`LANDMARK_PLACEMENTS`) | config `LANDMARK_PLACEMENTS` (still drift-checked against `placements.json` for map cuts) |

## Deliberately not moved

- The template's own world (Qaa El-Hamour setting, Sardine President, the Bureau's stamp, narrator
  names, interface words like "Swim back"): that is the product a fork gets, not the owner's
  brand. Content copy keys already cover the overlay titles and form words.
- Owner URLs in `docs/deploy.md`, `docs/testing.md` and two workflow `description:` examples: the
  owner's own docs. docs/template.md tells a fork to replace them.
- `apps/web-e2e/src/support/site.ts` (landmark names, copy): the e2e suite tests the shipped site;
  docs/template.md says to update it after rebranding.
- Internal keys (`qa3elhamor.locale`, `qa3elhamor.moderation-token`, package names): never visible.
