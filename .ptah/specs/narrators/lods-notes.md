# Narrator LODs: notes

Outputs (built by `npm run assets:compress`, deterministic; `assets:verify` green):

| id | tris | bytes | budget | height (source units) | source tris |
|---|---:|---:|---:|---:|---:|
| `spongebob-narrator` | 12,099 | 139,316 | 250 KiB, 12,500 tris | 10.033 | 519,664 |
| `patrick-narrator` | 9,780 | 61,704 | 200 KiB, 10,000 tris | 14.889 | 65,208 |

Both: lazy, `minimumTier: 'medium'`, feet at y = 0, x/z centred, facing +z (both sources already face +z, `stand.yaw = 0`),
source units (SpongeBob ~10 units tall, Patrick ~14.9; scale by `desired / standingHeight`). `placements.json` also records `height`.

## Method
- `stand` (pipeline.ts `standOnGround`): bake node transforms, yaw, centre, ground. Verified on every run (`verify.ts`).
- `simplifyAttributeAware`: Meshopt `simplifyWithAttributes` (UV, normal, colour weights) replaces glTF-Transform `simplify`,
  which is position-only and opened dark slits on SpongeBob's face.
- SpongeBob: 1.1% default ratio; Base 5%, EyeWhites 5%, Pupils 8%, Teeth 10%, Cheeks 5%, Eyelashes 4% (the body skin cracks
  at 1-2%); normal map and tangents dropped; textures 512 px WebP.
- Patrick: texture is a flat colour per quad, each quad its own UV island, so the simplifier stalled at 16k tris (and
  `Permissive` scrambled the UVs). Colour is baked to `COLOR_0` per triangle (UV centroid sample), normals smoothed per
  position, texture dropped, then simplified at 15%. 62 KB, no texture request.

## Manifest / pipeline changes
- `AssetEntry` gains optional `triangleBudget` and `standingHeight`; verify enforces both.
- New entries `spongebob-narrator`, `patrick-narrator` (sourceModel = the character model, so `shippedCredits()` lists them
  under the existing NickBob credits; spec added in `asset-manifest.spec.ts`).
- `placements.json` entries now carry `height` (null for non-standing assets).
- `simplify` is now attribute-aware for every asset: `spongebob-character` changed 550,520 -> 548,468 bytes, 77,936 -> 77,937 tris.
  All other outputs are byte-identical.
- Old full `spongebob-character` / `patrick-character`: KEPT. Nothing loads them by default, but the ambient `characters` config
  (libs/world/feature, apps/web ambient.config doc example) names them and I may not edit those. A consumer can place
  `spongebob-narrator` there instead. Follow-up: once `characters` examples point at the narrator LODs, delete the two
  full outputs (-1.4 MB repo, and their `quality-profile.spec.ts` assertions).
