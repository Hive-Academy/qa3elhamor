## Texture format decision

**WebP (`EXT_texture_webp`), not KTX2.** The KTX-Software `ktx`/`toktx` binary is not installed
here, and its only Windows distribution is an installer that writes to Program Files and edits
the system PATH, so it cannot be installed at user level. Per the brief this falls back to WebP
via `sharp` rather than blocking. All textures are 1024 px or smaller; quality is 80, 65 for the
environment (the map's atlas textures are flat colour and lose nothing visible, and the drop was
needed to clear its budget with margin).

WebP is decoded by the browser to full RGBA in GPU memory, where KTX2 would stay block-compressed.
With 134 KB of PNG across the four landmarks and 3.11 MiB across every raw model, that is not
significant for this MVP. The README documents how to switch to ETC1S; `KHRTextureBasisu` is
already registered, and the Basis transcoder lives in `three/examples/jsm/libs/basis/`.
No Basis transcoder is copied into `apps/web/public/basis/` because nothing emitted needs it.

## Geometry decisions worth knowing

- **Scale.** Landmark vertex data is scene-world (raw map coordinates x 0.01) with the ancestor
  scale baked in, so a landmark is small: the pineapple is about 0.08 x 0.13 x 0.08 units and the
  whole environment about 24 units across. `offset` is the scene-world position to place a landmark
  at to restore it to where it stood in the map.
- **Meshopt medium**, with normals at 8 bits and a shared quantisation volume for the skinned
  interior (details in the README). Positions are 14-bit, unchanged from `medium`.
- **UVs.** The map's UVs mostly lie outside [0,1], which stops the quantiser. Because every
  sampler repeats, each primitive's UVs are shifted by a whole number of tiles into [0,1) (samples
  identical texels) and snapped to a 1/2048 grid, which Meshopt compresses well. Primitives that still
  span more than one tile stay float32.
- **Indices** are U16 everywhere, including Patrick (65,208 triangles untouched).
- **Names.** Node, mesh, accessor, texture and skin names are cleared; nothing in the site reads
  them. Material names are kept.
- **Interior** keeps its 12-joint skin (merged from 60 per-mesh copies to one) and no animations.
- **Vertex colours** (`COLOR_0`) are kept on the map: they are not white (most vertices have a
  channel below 0.99), so stripping them would change the look.

## Loading in apps/web

For the `world-environment` item. Everything is Meshopt-compressed, so the decoder is required for
every asset; textures are WebP, which `GLTFLoader` handles natively, so no KTX2 loader is needed today.

```ts
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { MeshoptDecoder } from 'three/examples/jsm/libs/meshopt_decoder.module.js';

await MeshoptDecoder.ready; // the WASM decoder must be ready before the first load
const loader = new GLTFLoader();
loader.setMeshoptDecoder(MeshoptDecoder); // required: EXT_meshopt_compression is marked required

const environment = await loader.loadAsync('/models/environment.glb');
```

With React Three Fiber / drei, `useGLTF('/models/environment.glb')` already wires the Meshopt decoder
(its third argument, `useMeshopt`, defaults to true), so the snippet above is only needed for a bare `GLTFLoader`. Place each
landmark from `placements.json` (`landmark.position.set(...offset)`).

**If textures are later switched to KTX2** (see README), add, once per renderer:

```ts
import { KTX2Loader } from 'three/examples/jsm/loaders/KTX2Loader.js';

const ktx2 = new KTX2Loader()
  .setTranscoderPath('/basis/') // copy three/examples/jsm/libs/basis/* to apps/web/public/basis/
  .detectSupport(renderer); // renderer: the WebGLRenderer, e.g. useThree((s) => s.gl)
loader.setKTX2Loader(ktx2);
```

Lazy assets (`lazy: true`) should be fetched after first paint and gated on `minimumTier`.

## Verification

`npm run assets:verify` re-reads every emitted GLB with `NodeIO` and the Meshopt decoder
registered, and fails unless it parses, has more than zero triangles, and is at most `budgetBytes`.
`npm run assets:compress` runs the same check after building, plus the manifest-drift and
landmark-region checks described in the README.
